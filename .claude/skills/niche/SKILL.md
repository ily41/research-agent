# /niche: build the niche version

Product: `$ARGUMENTS`

1. Read `knowledge/niche-framework.md` and the latest `reports/check/check_*` for this product (if there isn't one, tell Rauf that running `/check-product` first is recommended, then continue with what you have).
2. Collect evidence for niche ideas:
   - Comments: complaints, questions ("does it work for…?", "ships to…?"), and who tags whom
   - Google Trends rising and Breakout queries for 2–3 names of the product
   - Instagram hashtags for each candidate buyer group (do they have an active content scene?)
   - Supplier listings: which versions already exist (sizes, colours, materials, bundles)
3. Build 3–5 niches with the 4 levers (audience / problem / offer / version). Each must pass the rules: one-line pitch, reachable with organic Reels, shown in 3 seconds, the supplier already makes it, no IP, and a buyer with money.
4. Rank them by evidence strength × margin × how easy the hook is. **Pick one.**

## Report: `reports/niche/niche_<YYYY-MM-DD>_<product>.md`
```
# Niche plan: <product> → <picked niche>
| Niche | One-liner | Lever(s) | Evidence | Hook idea | Risk |
## Pick: <niche>. Why (3 bullets)
## Target price and margin (cost, shipping, price, ≈ margin)
## 3 hook scripts (first 3 s action · on-screen text · middle reveal · CTA keyword + price on screen)
## Supplier search terms (AliExpress / CJ)
## What Rauf must do
```
In "What Rauf must do", put each step in bold: **search supplier with these terms**, **order 1–2 samples**, **film hook 1 first**.
